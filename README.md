# AvecIa

Projets réalisés entièrement avec l’aide de l’IA.

## steamLookUpIA

Application Java 25 / Spring Boot / Gradle en ligne de commande pour consulter un compte Steam : profil, bibliothèque, dix jeux les plus joués et activité récente.

Le projet se trouve dans [steamLookUpIa](steamLookUpIa/README.md). Ce dossier conserve son nom d’origine ; le nom de l’application et du projet Gradle est `steamLookUpIA`.

```sh
cd steamLookUpIa
./steam --help
./steam little_Almie
```

Voir le [guide complet](steamLookUpIa/README.md) pour configurer une clé Steam et lancer une recherche.
